# Clustering for PrefMaX

Clustering for PrefMaX

## Usage

``` r
prefmax_cluster(x, ncp = 2, nb.clust = NULL, max.clust = 6)
```

## Arguments

- x:

  PrefMaX object.

- ncp:

  Dimensions.

- nb.clust:

  Number of clusters.

- max.clust:

  Max cluster search count.

## Value

A list with PrefMaX clustering results.
