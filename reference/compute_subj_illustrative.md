# Helper unifie pour la projection des variables sujets

Helper unifie pour la projection des variables sujets

## Usage

``` r
compute_subj_illustrative(subj_mat, cons_coords, ndim, scale_subj = 1)
```

## Arguments

- subj_mat:

  Matrix of subject variables

- cons_coords:

  Consumer coordinates data frame

- ndim:

  Number of dimensions

- scale_subj:

  Scale factor for subject variables
