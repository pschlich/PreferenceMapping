# Computes PrefMaX analysis

Computes PrefMaX analysis

## Usage

``` r
prefmax(Y, X, scale.unit = FALSE, ncp = 5)
```

## Arguments

- Y:

  Liking matrix.

- X:

  Product variables matrix.

- scale.unit:

  Standardize product variables.

- ncp:

  Number of dimensions.

## Value

A list with PrefMaX model results.
