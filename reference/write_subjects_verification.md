# Helper pour l'ecriture des metadonnees Subjects dans Data_Verification

Helper pour l'ecriture des metadonnees Subjects dans Data_Verification

## Usage

``` r
write_subjects_verification(wb, sheet_name, subj_mat_full, start_row = 1)
```

## Arguments

- wb:

  Workbook object

- sheet_name:

  Target sheet name

- subj_mat_full:

  Full subject matrix

- start_row:

  Starting row
